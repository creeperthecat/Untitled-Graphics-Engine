\doxysubsection{Detailed Description}
\doxylink{classRenderer}{Renderer} class which handles rendering of objects. 

Internally stores a \doxylink{classCamera}{Camera}, \doxylink{classWindow}{Window} and a list of \doxylink{classObject}{Object} instances. User code can inherit \doxylink{classRenderer}{Renderer} and provide implementations of the \doxylink{classRenderer_a59c09ec7a99b4cafddc056893a049984}{start()} and \doxylink{classRenderer_a2c0c44152a14ace4713b51c325ebf5a7}{update()} functions.
