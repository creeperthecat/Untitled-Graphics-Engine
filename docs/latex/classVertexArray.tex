\doxysubsection{Detailed Description}
Implementation of \doxylink{classBuffer}{Buffer} using a VAO and VBO. 

Most basic and common implementation of vertex buffering. Can be inherited from to modify behaviour (see \doxylink{classEntityBuffer}{Entity\+Buffer}) Used by \doxylink{classPrimitive}{Primitive} instances.
