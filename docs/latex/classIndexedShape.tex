\doxysubsection{Detailed Description}
Helper class inheriting from \doxylink{classShape}{Shape} for use with \doxylink{classEntityBuffer}{Entity\+Buffer} objects to store and process vertices. 

Functionally equivalent to \doxylink{classShape}{Shape}, but now stores indices used for indexed drawing.
