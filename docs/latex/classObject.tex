\doxysubsection{Detailed Description}
Abstract class for creating and drawing objects. 

Used in \doxylink{classRenderer}{Renderer}. Can only be initialised after initialisation of \doxylink{classRenderer}{Renderer}. Derived classes must implement the draw function.
