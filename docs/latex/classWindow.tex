\doxysubsection{Detailed Description}
The \doxylink{classWindow}{Window} class is used to create an opengl context and a view of the scene. 

Used in \doxylink{classRenderer}{Renderer} during render loop. Must be initialised before initialisation of \doxylink{classObject}{Object}.
